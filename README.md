# Unimere｜一泓 · 展示页

Unimere 的界面和运行记录，包括网页工作台、平台控制台、QQ 生成案例，以及一个从 QQ 需求生成的扫雷游戏。

- 中文展示页：https://seele430.github.io/
- English page：https://seele430.github.io/en.html
- 主项目源码：https://github.com/seele430/unimere

截图来自本机实际运行。部分界面记录于 2026 年 11 月品牌更名前，因此仍能看到旧名称。

## 本地预览

```powershell
npm install
npm run dev
```

构建检查：

```powershell
npm run build
```

页面是静态 HTML，GitHub Pages 发布仓库根目录。Vite 用于本地预览和构建检查。
