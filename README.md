# Unimere｜一泓 · 展示页

> 万流入泓，诸事归一。
> Many flows. One clear space.

一个连接对话、任务、产物与消息的个人智能工作台。这里展示网页端、平台控制台、QQ 远程通道与真实运行产物。

- 在线预览：https://seele430.github.io/
- 主项目源码：https://github.com/seele430/unimere

截图均为本机真实运行界面；部分界面记录于品牌更名前（2026 年 11 月）。

## 本地预览

```powershell
npm install
npm run dev
```

展示页为静态 HTML，GitHub Pages 直接发布仓库根目录；`npm run build` 可用于额外检查资源打包。
