Platform console

The console covers queues, nodes, sandboxes, and executions. Acceptance, terminal state, and capacity changes are counted separately, so a 202 isn't read as a finished run.

202 means accepted only; hold is not scaling; capacity is counted from valid leases.
03

QQ remote channel

Send a request in QQ; the local service does the work and sends the result back.

Early versions used NapCat with a secondary account, whose login session often expired. The current version uses an official QQ Open Platform bot over an outbound persistent connection, so no public IP address is needed.

Posters keep their sources and verification status; figures not checked online are marked.

The same channel also produces HTML files.

05

Implementation notes

  • Multi-agent handoffsLeases, fencing, and idempotent steps coordinate handoffs. Runs can resume or continue after interruption without two processes writing the same step.
  • Test runnerSQLite and socket guards sit outside the tests. A test fails if it touches the real database or the network.
  • Metric definitionsThe meanings of 202, hold, and available capacity are defined in code and comments, with the frontend and backend using the same rules.
  • Artifact recordsArtifacts include SHA-256 hashes and previews, with diffs between two versions. Deletion requires a dry run followed by confirmation.
